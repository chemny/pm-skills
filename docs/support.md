# 支持范围与验证边界

本版正式支持范围：macOS、Codex、Python 3.13 或更新版本；实际执行环境为 Python 3.13。核心项目状态可用 JSON 语法保存为 `.yaml`，无需第三方包。读取通用 YAML 需要环境已有 PyYAML；缺失时报告，不自动安装。

| 环境 | 状态与边界 |
|---|---|
| macOS | 正式支持范围；本地文件、命令、安装管理与 Codex 原生调用实际验收。 |
| Codex | 使用实际 Skill 发现与 `type=skill` 输入验证；不把独立 App Server 通路冒充当前桌面共享进程或自动菜单点击。 |
| Windows 原生 | 不支持本版执行器；静态审查确认 `fcntl` 是 Unix 专用依赖。安装工具提前拒绝，不暗装兼容层。 |
| Claude Code | 规则文件可静态审阅，尚无本版实际加载/执行证据，不声明正式支持。 |
| Linux | 可选，未纳入本版正式验证。 |

桌面已安装同名旧入口时，新安装能否被正确选择须核对实际路径。调用名 `pm-skills`，显示名 `pm skills`。同名跨作用域入口的选择以实际客户端发现结果为准。

## 真实证据说明

现有源版本有125项确定性回归及原生正反调用记录，早期还有CSV软件与行动项Skill试点。职说最小页面完成真实实现、模型接线、浏览器和失败恢复验证。发布候选仍须取得本版独立安装、实际发现、调用和交付记录，不能仅引用旧报告表示新包已验收。

这些证据不保证任意模型、连接器或项目永不出错。检查器不认证用户身份或隔离宿主所有权限。任务相关的隐私、性能和业务质量按产品需求单独验收；职说模型遗漏待办等个例不进入通用规则。本版没有绑定任何会议模型，也不包含模型文件。

## 发布与维护

版本与逐文件清单见 `release.json`、`release-manifest.json`；更新/回退见安装说明。升级不自动改用户项目状态。旧状态按已有兼容规则读取，不把历史完成冒充新版本复验。问题可在项目仓库反馈，提交时避免附带凭证或私密项目内容。
