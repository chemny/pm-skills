# user-stories

完整读取 [专业规则](../methods/planning.md) 与 [文件契约](../artifact-contract.md)。主入口负责模式、范围和完成；本方法不维护独立阶段或另一份当前状态。

保留三C和INVEST、用户价值/设计引用/验收；故事表达是任务分解输入，不另建产品进度账。

以当前有效目标与规格为输入；缺用户承重决定先给有依据选项，研究/实现细节在授权内自行负责。按复杂度拆合材料，不以形式数量判定完成。具体工作步骤、产出与完成检查见上述专业规则，保留领域方法内容并在实际任务中应用。
