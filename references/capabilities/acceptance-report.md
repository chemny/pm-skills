# 按集成对象真实证据形成验收结论

先读取 [主流程](../workflow.md)、[文件契约](../artifact-contract.md)、[执行规则](../verification.md)、[恢复](../recovery.md)和[状态证据接口](../state-and-evidence.md)。专业要求按methods/verification或planning，不维护另一套PM-only交接/验收台账。

任务输入、依赖、范围、验证和完成条件明确，必要选择有真实依据。实现可由工具完成，但主Agent核实际结果和集成版本。不能以交接、计划或静态检查代替实现和验收，不自动安装别的套件或发布。
