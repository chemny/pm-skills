# 软件专项

需求覆盖用户任务、业务规则、数据和适用质量。使用设计可为界面、CLI、API或批处理；不强制网页。工程设计覆盖实际代码模块、接口、schema/迁移、依赖、运行/恢复，按任务够用。已有可执行规格优先引用。

实际产物是代码、配置、测试和可取得交付包。按适用性运行单元/真实集成/端到端/安全/性能/人工使用；模拟或静态不替代实际启动。数据使用合成或合法脱敏，凭证不进入普通证据。运行、安装、部署和发布权限分别核；在本地可用不声称线上已验证。

输入保护、错误路径、恢复、配置差异和集成回归按风险安排；不把任何供应商/技术栈作为所有项目默认答案。交付包含准确版本、实际使用说明、限制与接续。

新建软件必须按[new-project-gates](../new-project-gates.md)交需求、使用设计与适用原型/样例。ui默认核心流程原型；cli/api/service用可检查的调用、输入输出和错误恢复样例。已有有效基线的小改动按差异处理，新项目拆小仍为new。
